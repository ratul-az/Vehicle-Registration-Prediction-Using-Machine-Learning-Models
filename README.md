# Vehicle Registration Prediction Using Machine Learning Models

**Author:** MD. ZIHADUL AHSAN RATUL  
**Project type:** Supervised machine learning  
**Primary task:** Predict vehicle registration counts  
**Development environment:** Google Colab / Python

## Overview

This project explores machine-learning approaches for predicting vehicle registration numbers from historical registration data. The notebook includes model development, evaluation, hyperparameter tuning and visual comparison.

The primary regression workflow uses vehicle-related and date-related inputs to predict the `registrations` target.

## Models covered in the notebook

- **XGBoost Regressor** — baseline model, GridSearchCV tuning, evaluation, feature importance and cross-validation.
- **Random Forest** — the notebook contains both a Random Forest Classifier section (predicting the `fuel` category) and a Random Forest Regressor section.
- **Decision Tree Regressor** — baseline and optimized model, model comparison and feature-importance visualizations.
- **Gradient Boosting Regressor** — training, evaluation and performance visualizations.

The notebook also includes a final comparison of Gradient Boosting, Decision Tree, Random Forest and XGBoost.

## Main regression workflow

The XGBoost section documents these input features:

- Month
- Year
- Day
- Vehicle Type
- Fuel Type

**Target variable:** `registrations` (number of vehicle registrations).

The XGBoost workflow includes:
1. Dataset overview and data-quality checks.
2. Exploratory data analysis.
3. Preprocessing and categorical encoding.
4. Train/test split.
5. Baseline XGBoost regression.
6. Hyperparameter optimization using `GridSearchCV`.
7. Evaluation using MAE, RMSE and R².
8. Actual-versus-predicted and error analysis.
9. Feature-importance analysis.
10. Five-fold cross-validation and model saving.

## Dataset requirements

The notebook expects a CSV file named:

```text
cleaned_registrations.csv
```

The CSV is **not included** in this repository package because it was not supplied with the notebook. The original notebook does not identify a verifiable public download URL or dataset publisher, so this documentation does not invent one.

To run the notebook:
1. Obtain the same `cleaned_registrations.csv` dataset used in the original work.
2. Upload it to the Google Colab session, or place it in the working directory for a local run.
3. Ensure the file path matches the path used by the relevant notebook section. Some cells use `cleaned_registrations.csv`; others use `/content/cleaned_registrations.csv`.
4. Run the notebook sequentially, checking that the dataset columns match the notebook's expected target and feature names.

See [DATASET.md](DATASET.md) for more detail.

## Important notebook notes

- The notebook contains multiple model experiments and some repeated data-loading/preprocessing workflows.
- The Random Forest section includes a classification experiment for predicting `fuel`, in addition to a separate Random Forest regression experiment.
- The Gradient Boosting section contains fallback logic that may select the last numeric column as a placeholder target if it cannot identify a target column. Confirm that the selected target is `registrations` before interpreting its results.
- The final comparison charts use fixed values entered directly in the notebook. They should be interpreted as the recorded comparison values, not as a live benchmark that updates automatically.
- The original notebook is preserved as supplied; this package adds documentation and does not rewrite or validate the experiments.

## Limitations

This is an educational machine-learning project. Its predictions depend on the quality, coverage and representativeness of the historical registration dataset. It should not be treated as an official vehicle-registration forecast or used as the sole basis for policy, business or investment decisions.
